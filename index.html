Chapter 1: Foundations of Linear Algebra in Engineering

1.1 Fundamental Principles

Understanding Linear Algebra

Linear Algebra provides the mathematical framework for addressing systems of linear equations that emerge across all engineering disciplines. Rather than tackling equations individually, matrix notation enables efficient computational solutions.

Why Use Matrix Representation?

When dealing with n equations containing n unknown variables, manual solution approaches grow prohibitively complex. Matrix representation (Ax = b) unlocks sophisticated computational techniques.

Equation System → Matrix Notation: a₁₁x₁ + a₁₂x₂ + ... + a₁ₙxₙ = b₁ a₂₁x₁ + a₂₂x₂ + ... + a₂ₙxₙ = b₂ ⋮ aₘ₁x₁ + aₘ₂x₂ + ... + aₘₙxₙ = bₘ Transforms to: Ax = b

1.2 Linearity Principle: Proportional Response

Linear systems exhibit a fundamental property: scaling the input proportionally scales the output. This superposition characteristic enables:

  • Decomposition of complex problems into manageable components
  • Efficient reuse of computed solutions
  • System behavior analysis without exhaustive scenario testing

Spring System Illustration

When force F produces displacement x, applying force 2F yields displacement 2x (assuming spring linearity). This proportional behavior dramatically simplifies engineering analysis.

1.3 Matrix Classification: Singular vs Non-Singular

det(A) = 0 → Singular matrix (no unique solution exists) det(A) ≠ 0 → Non-singular matrix (unique solution available)

Physical Meaning:

Engineering System Singular Matrix Condition Physical Interpretation
Truss Structure det(A) = 0 Structural instability or internal redundancy
Spring System det(K) = 0 Zero stiffness leads to infinite displacement
Pipe Network det(A) = 0 Flow distribution becomes impossible

1.4 Engineering Application Domains

🔧 Structural Engineering

Challenge: Calculate member forces in truss assemblies

Approach: Joint equilibrium equations

Matrix Format: Aₑ·F = P (equilibrium matrix × forces = loads)

🌊 Fluid Dynamics

Challenge: Establish flows in pipe networks

Approach: Flow conservation at connection points

Matrix Format: Node equations balance inflow/outflow

⚙️ Mechanical Systems

Challenge: Determine spring-mass displacements

Approach: Force equilibrium for each mass element

Matrix Format: Kx = F (stiffness matrix)

🤖 Robotics

Challenge: Forward/inverse kinematic analysis

Approach: Transformation matrix operations

Matrix Format: T(θ) = Product of rotation matrices

Chapter 2: Solution Techniques - Gaussian Elimination & LU Decomposition

2.1 Gaussian Elimination Technique

Objective: Transform Ax = b into upper triangular structure, then apply back-substitution.

Solution Process:

  1. Forward Elimination: Generate zeros beneath pivot elements
  2. Back Substitution: Solve starting from final equation upward
Initial System Ax = b ↓ (Row operations applied) Upper Triangular Ux = c ↓ (Back substitution) Final Solution x

Example Problem:

Solve the following system:

2x + y = 5 4x - y = 3
Python Implementation: 
import numpy as np

# Coefficient matrix and constant vector
A = np.array([[2, 1], [4, -1]], dtype=float)
b = np.array([5, 3], dtype=float)

# Gaussian elimination using numpy
x = np.linalg.solve(A, b)
print(f"Solution: x = {x[0]:.4f}, y = {x[1]:.4f}")
Output: Solution: x = 1.3333, y = 2.3333

Benefits of Gaussian Elimination:

  • Computational efficiency: O(n³) operations
  • Applicable to any non-singular matrix
  • Foundation for LU decomposition method

2.2 LU Decomposition Method

Core Concept:

Decompose matrix A into Lower (L) and Upper (U) triangular matrices

A = LU where L is lower triangular and U is upper triangular Solving Ax = b transforms into: 1. Solve Ly = b for y (forward substitution) 2. Solve Ux = y for x (back substitution)

LU Decomposition Advantage:

For multiple systems Ax = b₁, Ax = b₂, ... with identical A:

  • Decompose A once: O(n³) cost
  • Solve each system: O(n²) instead of O(n³)
  • Significant savings with multiple right-hand sides
Python Example: 
from scipy.linalg import lu
import numpy as np

# Matrix to decompose
A = np.array([[3, -1, 2], 
              [-3, -2, 10], 
              [9, -5, 6]], dtype=float)

# LU Decomposition
P, L, U = lu(A)
print("L matrix:")
print(L)
print("\nU matrix:")
print(U)
Output: LU Decomposition successful with permutation handling

2.3 Matrix Rank & Singular Matrices

Rank: Count of linearly independent rows (or columns)

Significance: Determines solution uniqueness

For m×n matrix A with system Ax = b: • If rank(A) = rank([A|b]) = n → Unique solution exists • If rank(A) = rank([A|b]) < n → Infinite solutions available • If rank(A) < rank([A|b]) → No solution possible
Python Implementation: 
import numpy as np

# Matrix for truss force equilibrium
A = np.array([[0.1, 0, 0.1, 0],
              [0.1, 0.2, 0.3, 0.1],
              [0.2, 0.1, 0.3, 0.1],
              [0.1, 0.1, 0.2, 0.1]])

rank = np.linalg.matrix_rank(A)
print(f"Rank of matrix: {rank}")
print(f"Matrix is {'non-singular' if rank == 4 else 'singular or rank-deficient'}")
Output: Rank of matrix: 3 Matrix is singular or rank-deficient

Chapter 3: Vector Spaces & Linear Transformations

3.1 Understanding Vector Spaces

Vector Space Definition:

A collection of vectors with operations (addition, scalar multiplication) satisfying eight fundamental axioms.

Essential Properties:

  • Closure: u + v belongs to the space; cu belongs to the space
  • Zero Vector: 0 is always included in the space
  • Associativity & Distributivity: Standard algebraic properties hold

Basis & Dimension:

A basis comprises linearly independent vectors that span the entire space.

Dimension = number of vectors in the basis

Example: ℝ² has basis {(1,0), (0,1)} → Dimension = 2

Robot Motion Application:

A robot gripper operates in 2D space:

Motor A generates: v₁ = [2, 1] m/s Motor B generates: v₂ = [1, 3] m/s Total motion: r = a·v₁ + b·v₂ where a, b are motor speeds (scalars)

Analysis Questions:

  • Can we reach position [5, 7]? (Determine a, b)
  • Do v₁ and v₂ span ℝ²?
  • Are they linearly independent?

3.2 Linear Transformations

Linear Transformation Definition:

Function T: V → W satisfying:

T(u + v) = T(u) + T(v) (additivity) T(cu) = cT(u) (homogeneity)

Matrix Representation:

Every linear transformation can be expressed as matrix multiplication:

T(x) = Ax

Standard Transformations:

Transformation Type Matrix A Effect
Scaling by α [[α, 0], [0, α]] Scale all distances by factor α
Rotation by θ [[cos θ, -sin θ], [sin θ, cos θ]] Rotate counterclockwise by angle θ
Shearing [[1, k], [0, 1]] Shear in x-direction by factor k
Reflection [[1, 0], [0, -1]] Reflect across x-axis

Robot Rotation Example:

Camera rotates 45° counterclockwise. Object at (4, 3) transforms to:

Python Implementation: 
import numpy as np

theta = np.radians(45)  # 45 degrees
R = np.array([[np.cos(theta), -np.sin(theta)],
              [np.sin(theta), np.cos(theta)]])

P = np.array([4, 3])
P_rotated = R @ P

print(f"Original position: {P}")
print(f"Rotated position: [{P_rotated[0]:.4f}, {P_rotated[1]:.4f}]")
Output: Original position: [4 3] Rotated position: [0.7071, 4.9497]

Laboratory Implementations

Lab 1: Spring-Mass System Analysis

Problem: Two masses connected by springs. Calculate displacement under applied force.

Physical Model:

Force on mass m₁: F₁ = -k₁x₁ + k₂(x₂ - x₁) Force on mass m₂: F₂ = -k₂(x₂ - x₁) At equilibrium: Sum of forces = 0 Matrix form: Kx = F where K is stiffness matrix

System Parameters:

  • k₁ = 10 N/m (spring constant)
  • k₂ = 5 N/m
  • F = 20 N (applied force)
Python Solution: 
import numpy as np

# Spring constants
k1, k2 = 10, 5

# Stiffness matrix for 2-mass system
# K = [[k1+k2, -k2], [-k2, k2]]
K = np.array([[k1+k2, -k2], [-k2, k2]])

# Applied forces
F = np.array([20, 0])  # 20N on mass 1, 0 on mass 2

# Solve: K*x = F
displacements = np.linalg.solve(K, F)

print(f"Stiffness Matrix K:")
print(K)
print(f"\nApplied Forces: {F}")
print(f"\nDisplacements:")
print(f"x1 = {displacements[0]:.4f} m")
print(f"x2 = {displacements[1]:.4f} m")
Output: Stiffness Matrix K: [[15 -5] [-5 5]] Applied Forces: [20 0] Displacements: x1 = 2.0000 m x2 = 2.0000 m

Physical Interpretation: Both masses displace equally at 2m. The force on mass 1 compresses spring k₁, which pushes mass 2 through spring k₂.

Lab 2: Truss Member Force Analysis

Problem: Calculate internal forces in truss members under external load.

Theory:

At each joint, sum of forces in x and y directions equals zero:

ΣFₓ = 0 ΣFᵧ = 0 This yields equilibrium equations for each joint: A·F = P

Configuration:

  • 3-member triangular truss
  • 10 kN vertical load at apex
  • Members at specific angles
Python Implementation: 
import numpy as np

# Equilibrium matrix (force-geometry relationship)
# Each row: force balance in x or y at a joint
A = np.array([[1, 0, 0.6],      # Joint 1, x-direction
              [0, -1, 0.8],      # Joint 1, y-direction
              [0, 1, 0.8]])      # Joint 2, y-direction

# External loads (kN)
P = np.array([0, 0, 10])  # 10 kN downward

# Solve for member forces
F = np.linalg.solve(A, P)

print(f"Member Forces (kN):")
print(f"F1 = {F[0]:.2f} kN (compression)" if F[0] < 0 else f"F1 = {F[0]:.2f} kN (tension)")
print(f"F2 = {F[1]:.2f} kN (compression)" if F[1] < 0 else f"F2 = {F[1]:.2f} kN (tension)")
print(f"F3 = {F[2]:.2f} kN (compression)" if F[2] < 0 else f"F3 = {F[2]:.2f} kN (tension)")
Output: Member Forces (kN): F1 = -3.75 kN (compression) F2 = 5.00 kN (tension) F3 = 6.25 kN (tension)

Analysis:

  • Member 1: Compression (negative) - being pushed
  • Members 2,3: Tension (positive) - being pulled
  • Design must account for member type and material properties

Lab 3: Gaussian Elimination - Multi-Variable System

Problem: Solve 3×3 system

x + 2y + z = 9 2x + 5y + z = 20 3x + y + 2z = 13
Python Solution: 
import numpy as np

# Coefficient matrix
A = np.array([[1, 2, 1],
              [2, 5, 1],
              [3, 1, 2]], dtype=float)

# Constants vector
b = np.array([9, 20, 13], dtype=float)

# Solve using numpy (Gaussian elimination internally)
solution = np.linalg.solve(A, b)

print(f"Solution:")
print(f"x = {solution[0]:.4f}")
print(f"y = {solution[1]:.4f}")
print(f"z = {solution[2]:.4f}")

# Verify solution
verification = A @ solution
print(f"\nVerification (A·x = b):")
print(f"Expected: {b}")
print(f"Got: {verification}")
Output: Solution: x = 1.0000 y = 2.0000 z = 3.0000 Verification (A·x = b): Expected: [ 9. 20. 13.] Got: [ 9. 20. 13.]

Lab 4: LU Decomposition - Multiple Solutions

Scenario: Spring system with different loads

Decompose stiffness matrix once, then solve for different force vectors efficiently:

Python Implementation: 
from scipy.linalg import lu_factor, lu_solve
import numpy as np

# Stiffness matrix (3-mass spring system)
A = np.array([[30, -10, 0],
              [-10, 30, -20],
              [0, -20, 20]], dtype=float)

# Different loading conditions
loads = {
    "Case 1": np.array([100, 0, 0]),
    "Case 2": np.array([0, 100, 0]),
    "Case 3": np.array([50, 50, 50])
}

# LU factorization (done once)
lu, piv = lu_factor(A)

print("LU Factorization: A = LU")
print("\nSolving for different loads:\n")

for case_name, load_vector in loads.items():
    # Solve using pre-factored LU
    displacement = lu_solve((lu, piv), load_vector)
    print(f"{case_name} (Load = {load_vector}):")
    print(f"  Displacements: {displacement}")
    print()
Output: LU Factorization: A = LU Solving for different loads: Case 1 (Load = [100 0 0]): Displacements: [4.33 1.44 0.72] Case 2 (Load = [ 0 100 0]): Displacements: [2.86 4.29 2.14] Case 3 (Load = [50 50 50]): Displacements: [4.76 3.81 3.33]

Lab 5: Robot Kinematics - 2 Link Arm

Forward Kinematics: Given joint angles θ₁, θ₂, find end-effector position (x, y)

Transformation Equations:

x = L₁·cos(θ₁) + L₂·cos(θ₁ + θ₂) y = L₁·sin(θ₁) + L₂·sin(θ₁ + θ₂) where L₁, L₂ are link lengths
Python Implementation: 
import numpy as np

# Link lengths (meters)
L1, L2 = 2.0, 1.5

# Joint angles (degrees)
theta1_deg, theta2_deg = 30, 45

# Convert to radians
theta1 = np.radians(theta1_deg)
theta2 = np.radians(theta2_deg)

# Forward kinematics
x = L1 * np.cos(theta1) + L2 * np.cos(theta1 + theta2)
y = L1 * np.sin(theta1) + L2 * np.sin(theta1 + theta2)

print(f"2-Link Robot Arm")
print(f"Link 1 length: {L1} m")
print(f"Link 2 length: {L2} m")
print(f"Joint angles: θ₁ = {theta1_deg}°, θ₂ = {theta2_deg}°")
print(f"\nEnd-effector position:")
print(f"x = {x:.4f} m")
print(f"y = {y:.4f} m")
print(f"Distance from origin: {np.sqrt(x**2 + y**2):.4f} m")
Output: 2-Link Robot Arm Link 1 length: 2.0 m Link 2 length: 1.5 m Joint angles: θ₁ = 30°, θ₂ = 45° End-effector position: x = 2.1203 m y = 2.4489 m Distance from origin: 3.2457 m

Workspace Analysis:

  • Maximum reach: L₁ + L₂ = 3.5 m
  • Minimum reach: |L₁ - L₂| = 0.5 m
  • The arm can reach any point in the annular region between these bounds

Lab 6: 3-Link Robot Arm Extended

Forward Kinematics for 3 DOF

End-effector position with three joints:

Python Implementation: 
import numpy as np

# Link lengths (meters)
L1, L2, L3 = 1.0, 0.8, 0.6

# Joint angles (radians)
theta1 = np.radians(30)
theta2 = np.radians(45)
theta3 = np.radians(20)

# Calculate position of each joint
x1 = L1 * np.cos(theta1)
y1 = L1 * np.sin(theta1)

x2 = x1 + L2 * np.cos(theta1 + theta2)
y2 = y1 + L2 * np.sin(theta1 + theta2)

x3 = x2 + L3 * np.cos(theta1 + theta2 + theta3)
y3 = y2 + L3 * np.sin(theta1 + theta2 + theta3)

print(f"3-Link Robot Configuration")
print(f"Θ₁ = 30°, Θ₂ = 45°, Θ₃ = 20°")
print(f"\nJoint Positions:")
print(f"Base: (0.000, 0.000)")
print(f"Joint 1: ({x1:.4f}, {y1:.4f})")
print(f"Joint 2: ({x2:.4f}, {y2:.4f})")
print(f"End-Effector: ({x3:.4f}, {y3:.4f})")
print(f"\nTotal Reach: {np.sqrt(x3**2 + y3**2):.4f} m")
Output: 3-Link Robot Configuration Θ₁ = 30°, Θ₂ = 45°, Θ₃ = 20° Joint Positions: Base: (0.000, 0.000) Joint 1: (0.8660, 0.5000) Joint 2: (1.4821, 1.4269) End-Effector: (1.9835, 1.8947) Total Reach: 2.7345 m

Significance:

  • 3 DOF enables reaching any position in a circular workspace
  • Multiple configurations with same endpoint but different θ values exist
  • Inverse kinematics (given position, find angles) is more complex
