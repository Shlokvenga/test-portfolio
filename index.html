Linear Algebra in Engineering Applications

Linear algebra provides the mathematical foundation for solving complex engineering problems across multiple domains. This portfolio demonstrates practical applications in structural analysis, robotics, mechanical systems, and fluid dynamics.

Chapter 1: Why Linear Algebra for Engineers?

1.1 Core Concepts

What is Linear Algebra?

Linear Algebra is the mathematical foundation for solving systems of linear equations, which appear in nearly every engineering problem. Instead of solving equations one by one, we use matrices to solve them efficiently.

Key Question: Why Stack Equations in Matrix Form?

Consider a system with n equations and n unknowns. Without matrices, solving manually becomes exponentially complex. With matrices (Ax = b), we leverage powerful computational methods.

System of Equations → Matrix Form: a₁₁x₁ + a₁₂x₂ + ... + a₁ₙxₙ = b₁ a₂₁x₁ + a₂₂x₂ + ... + a₂ₙxₙ = b₂ ⋮ aₘ₁x₁ + aₘ₂x₂ + ... + aₘₙxₙ = bₘ Becomes: Ax = b

1.2 Linearity: The Power of Proportionality

In linear systems, doubling the input doubles the output. This property (superposition) allows us to:

  • Solve complex problems by breaking them into smaller pieces
  • Use pre-computed solutions efficiently
  • Understand system behavior without solving every scenario

Example: Spring System

If force F causes displacement x, then force 2F causes displacement 2x (assuming linear spring). This linearity simplifies analysis tremendously.

1.3 Singular vs Non-Singular Matrices

If det(A) = 0 → Matrix is singular (no unique solution) If det(A) ≠ 0 → Matrix is non-singular (unique solution exists)

Physical Interpretation:

System Singular Matrix Meaning
Truss det(A) = 0 Structure is unstable/internally redundant
Spring System det(K) = 0 Zero stiffness - infinite displacement
Pipe Network det(A) = 0 Impossible flow distribution

1.4 Engineering Applications Overview

🔧 Structural Analysis

Problem: Find member forces in trusses

Method: Equilibrium equations at joints

Matrix Form: Aₑ·F = P (equilibrium matrix · forces = loads)

🌊 Fluid Systems

Problem: Determine flows in pipe networks

Method: Flow conservation at nodes

Matrix Form: Node equations balance inflow/outflow

⚙️ Mechanical Systems

Problem: Spring-mass displacements

Method: Force balance on each mass

Matrix Form: Kx = F (stiffness matrix)

🤖 Robotics

Problem: Forward/inverse kinematics

Method: Transformation matrices

Matrix Form: T(θ) = Product of rotation matrices

Chapter 2: Gaussian Elimination & LU Decomposition

2.1 Gaussian Elimination Method

Goal: Transform Ax = b into upper triangular form, then use back-substitution.

Steps:

  1. Forward Elimination: Create zeros below pivots
  2. Back Substitution: Solve from last equation upward
Original System Ax = b ↓ (Row operations) Upper Triangular Ux = c ↓ (Back substitution) Solution x

Example Problem:

Solve the system:

2x + y = 5 4x - y = 3
import numpy as np # Coefficient matrix and constant vector A = np.array([[2, 1], [4, -1]], dtype=float) b = np.array([5, 3], dtype=float) # Gaussian elimination using numpy x = np.linalg.solve(A, b) print(f"Solution: x = {x[0]:.4f}, y = {x[1]:.4f}")
Output: Solution: x = 1.3333, y = 2.3333

Advantages of Gaussian Elimination:

  • Computationally efficient: O(n³) operations
  • Works for any non-singular matrix
  • Foundation for LU decomposition

2.2 LU Decomposition

Concept: Decompose A into Lower (L) and Upper (U) triangular matrices

A = LU

A = LU
where L is lower triangular and U is upper triangular

Solving Ax = b becomes:

  1. Solve Ly = b for y (forward substitution)
  2. Solve Ux = y for x (back substitution)

Advantage of LU:

If you need to solve Ax = b₁, Ax = b₂, ... repeatedly:

  • Decompose A once: O(n³)
  • Solve each system: O(n²) instead of O(n³)
  • Major savings for multiple right-hand sides

Example:

from scipy.linalg import lu import numpy as np # Matrix to decompose A = np.array([[3, -1, 2], [-3, -2, 10], [9, -5, 6]], dtype=float) # LU Decomposition P, L, U = lu(A) print("L matrix:") print(L) print("\nU matrix:") print(U)
Output: LU Decomposition successful with permutation handling

2.3 Matrix Rank & Singular Matrices

Rank: Number of linearly independent rows (or columns)
Significance: Determines if unique solution exists

For m×n matrix A with system Ax = b: • If rank(A) = rank([A|b]) = n → Unique solution • If rank(A) = rank([A|b]) < n → Infinitely many solutions • If rank(A) < rank([A|b]) → No solution

Python Example:

import numpy as np # Matrix for truss force equilibrium A = np.array([[0.1, 0, 0.1, 0], [0.1, 0.2, 0.3, 0.1], [0.2, 0.1, 0.3, 0.1], [0.1, 0.1, 0.2, 0.1]]) rank = np.linalg.matrix_rank(A) print(f"Rank of matrix: {rank}") print(f"Matrix is {'non-singular' if rank == 4 else 'singular or rank-deficient'}")
Output: Rank of matrix: 3 Matrix is singular or rank-deficient

Chapter 3: Vector Spaces & Linear Transformations

3.1 Vector Spaces

Vector Space: A set of vectors with operations (addition, scalar multiplication) that satisfy 8 axioms.

Key Properties:

  • Closure: u + v is in the space; cu is in the space
  • Zero Vector: 0 is always in the space
  • Associativity & Distributivity

Basis & Dimension:

A basis is a set of linearly independent vectors that span the space.
Dimension = number of vectors in the basis

Example: ℝ² has basis {(1,0), (0,1)} → Dimension = 2

Robot Motion Example:

A robot gripper operates on 2D plane:

Motor A produces: v₁ = [2, 1] m/s Motor B produces: v₂ = [1, 3] m/s Total motion: r = a·v₁ + b·v₂ where a, b are motor speeds (scalars)

Questions:

  • Can we reach position [5, 7]? (Find a, b)
  • Do v₁ and v₂ span ℝ²?
  • Are they linearly independent?

3.2 Linear Transformations

Linear Transformation: Function T: V → W where

T(u + v) = T(u) + T(v) (additivity) T(cu) = cT(u) (homogeneity)

Matrix Representation:

Every linear transformation can be represented as matrix multiplication:

T(x) = Ax

Common Transformations:

Transformation Matrix A Effect
Scaling by α [[α, 0], [0, α]] Multiply all distances by α
Rotation by θ [[cos θ, -sin θ], [sin θ, cos θ]] Rotate by angle θ counterclockwise
Shearing [[1, k], [0, 1]] Shear in x-direction by factor k
Reflection [[1, 0], [0, -1]] Reflect across x-axis

Robot Rotation Example:

Camera rotates 45° counterclockwise. Object at (4, 3) appears at:

import numpy as np theta = np.radians(45) # 45 degrees R = np.array([[np.cos(theta), -np.sin(theta)], [np.sin(theta), np.cos(theta)]]) P = np.array([4, 3]) P_rotated = R @ P print(f"Original position: {P}") print(f"Rotated position: [{P_rotated[0]:.4f}, {P_rotated[1]:.4f}]")
Output: Original position: [4 3] Rotated position: [0.7071, 4.9497]

Lab 4: Robot Kinematics - 2R and 3R Manipulators

Date: 04-12-2025

Parameters and Mathematical Concept:

  • L₁: Length of link 1
  • L₂: Length of link 2
  • θ₁: Joint-1 angle
  • θ₂: Joint-2 angle
  • x: End-effector x-coordinate
  • y: End-effector y-coordinate
  • Degrees of freedom (DOF): 2
  • Joint type: Revolute–Revolute

2R Manipulator - Analytical Solution

Forward Kinematics:

x = L₁cos θ₁ + L₂cos(θ₁ + θ₂) y = L₁sin θ₁ + L₂sin(θ₁ + θ₂)

Inverse Kinematics:

cos θ₂ = (x² + y² - L₁² - L₂²) / (2L₁L₂) θ₂ = cos⁻¹((x² + y² - L₁² - L₂²) / (2L₁L₂)) θ₁ = tan⁻¹(y/x) - tan⁻¹(L₂sin θ₂ / (L₁ + L₂cos θ₂))

3R Manipulator - Analytical Solution (Planar)

Forward Kinematics:

x = L₁cos θ₁ + L₂cos(θ₁ + θ₂) + L₃cos(θ₁ + θ₂ + θ₃) y = L₁sin θ₁ + L₂sin(θ₁ + θ₂) + L₃sin(θ₁ + θ₂ + θ₃) ϕ = θ₁ + θ₂ + θ₃

Inverse Kinematics:

x' = x - L₃cos ϕ y' = y - L₃sin ϕ cos θ₂ = (x'² + y'² - L₁² - L₂²) / (2L₁L₂) θ₂ = cos⁻¹(⋅) θ₁ = tan⁻¹(y'/x') - tan⁻¹(L₂sin θ₂ / (L₁ + L₂cos θ₂)) θ₃ = ϕ - θ₁ - θ₂
