Chapter 1: Foundations of Linear Algebra in Engineering

1.1 Fundamental Principles

Understanding Linear Algebra

Linear Algebra provides the mathematical framework for addressing systems of linear equations that emerge across all engineering disciplines. Rather than tackling equations individually, matrix notation enables efficient computational solutions.

Why Use Matrix Representation?

When dealing with n equations containing n unknown variables, manual solution approaches grow prohibitively complex. Matrix representation (Ax = b) unlocks sophisticated computational techniques.

Equation System → Matrix Notation: a₁₁x₁ + a₁₂x₂ + ... + a₁ₙxₙ = b₁ a₂₁x₁ + a₂₂x₂ + ... + a₂ₙxₙ = b₂ ⋮ aₘ₁x₁ + aₘ₂x₂ + ... + aₘₙxₙ = bₘ Transforms to: Ax = b

1.2 Linearity Principle: Proportional Response

Linear systems exhibit a fundamental property: scaling the input proportionally scales the output. This superposition characteristic enables:

  • Decomposition of complex problems into manageable components
  • Efficient reuse of computed solutions
  • System behavior analysis without exhaustive scenario testing

Spring System Illustration

When force F produces displacement x, applying force 2F yields displacement 2x (assuming spring linearity). This proportional behavior dramatically simplifies engineering analysis.

1.3 Matrix Classification: Singular vs Non-Singular

det(A) = 0 → Singular matrix (no unique solution exists) det(A) ≠ 0 → Non-singular matrix (unique solution available)

Physical Meaning:

Engineering System Singular Matrix Condition Physical Interpretation
Truss Structure det(A) = 0 Structural instability or internal redundancy
Spring System det(K) = 0 Zero stiffness leads to infinite displacement
Pipe Network det(A) = 0 Flow distribution becomes impossible

Chapter 2: Solution Techniques - Gaussian Elimination & LU Decomposition

2.1 Gaussian Elimination Technique

Objective: Transform Ax = b into upper triangular structure, then apply back-substitution.

Solution Process:

  1. Forward Elimination: Generate zeros beneath pivot elements
  2. Back Substitution: Solve starting from final equation upward
Initial System Ax = b ↓ (Row operations applied) Upper Triangular Ux = c ↓ (Back substitution) Final Solution x

Example Problem:

Solve the following system:

2x + y = 5 4x - y = 3
Python Implementation: 
import numpy as np

# Coefficient matrix and constant vector
A = np.array([[2, 1], [4, -1]], dtype=float)
b = np.array([5, 3], dtype=float)

# Gaussian elimination using numpy
x = np.linalg.solve(A, b)
print(f"Solution: x = {x[0]:.4f}, y = {x[1]:.4f}")
Output: Solution: x = 1.3333, y = 2.3333

Benefits of Gaussian Elimination:

  • Computational efficiency: O(n³) operations
  • Applicable to any non-singular matrix
  • Foundation for LU decomposition method

2.2 LU Decomposition Method

Core Concept:

Decompose matrix A into Lower (L) and Upper (U) triangular matrices

A = LU where L is lower triangular and U is upper triangular Solving Ax = b transforms into: 1. Solve Ly = b for y (forward substitution) 2. Solve Ux = y for x (back substitution)

LU Decomposition Advantage:

For multiple systems Ax = b₁, Ax = b₂, ... with identical A:

  • Decompose A once: O(n³) cost
  • Solve each system: O(n²) instead of O(n³)
  • Significant savings with multiple right-hand sides
Python Example: 
from scipy.linalg import lu
import numpy as np

# Matrix to decompose
A = np.array([[3, -1, 2], 
              [-3, -2, 10], 
              [9, -5, 6]], dtype=float)

# LU Decomposition
P, L, U = lu(A)
print("L matrix:")
print(L)
print("\nU matrix:")
print(U)
Output: LU Decomposition successful with permutation handling

2.3 Matrix Rank & Singular Matrices

Rank: Count of linearly independent rows (or columns)

Significance: Determines solution uniqueness

For m×n matrix A with system Ax = b: • If rank(A) = rank([A|b]) = n → Unique solution exists • If rank(A) = rank([A|b]) < n → Infinite solutions available • If rank(A) < rank([A|b]) → No solution possible
Python Implementation: 
import numpy as np

# Matrix for truss force equilibrium
A = np.array([[0.1, 0, 0.1, 0],
              [0.1, 0.2, 0.3, 0.1],
              [0.2, 0.1, 0.3, 0.1],
              [0.1, 0.1, 0.2, 0.1]])

rank = np.linalg.matrix_rank(A)
print(f"Rank of matrix: {rank}")
print(f"Matrix is {'non-singular' if rank == 4 else 'singular or rank-deficient'}")
Output: Rank of matrix: 3 Matrix is singular or rank-deficient

Chapter 3: Vector Spaces & Linear Transformations

3.1 Understanding Vector Spaces

Vector Space Definition:

A collection of vectors with operations (addition, scalar multiplication) satisfying eight fundamental axioms.

Essential Properties:

  • Closure: u + v belongs to the space; cu belongs to the space
  • Zero Vector: 0 is always included in the space
  • Associativity & Distributivity: Standard algebraic properties hold

Basis & Dimension:

A basis comprises linearly independent vectors that span the entire space.

Dimension = number of vectors in the basis

Example: ℝ² has basis {(1,0), (0,1)} → Dimension = 2

Robot Motion Application:

A robot gripper operates in 2D space:

Motor A generates: v₁ = [2, 1] m/s Motor B generates: v₂ = [1, 3] m/s Total motion: r = a·v₁ + b·v₂ where a, b are motor speeds (scalars)

Analysis Questions:

  • Can we reach position [5, 7]? (Determine a, b)
  • Do v₁ and v₂ span ℝ²?
  • Are they linearly independent?

3.2 Linear Transformations

Linear Transformation Definition:

Function T: V → W satisfying:

T(u + v) = T(u) + T(v) (additivity) T(cu) = cT(u) (homogeneity)

Matrix Representation:

Every linear transformation can be expressed as matrix multiplication:

T(x) = Ax

Standard Transformations:

Transformation Type Matrix A Effect
Scaling by α [[α, 0], [0, α]] Scale all distances by factor α
Rotation by θ [[cos θ, -sin θ], [sin θ, cos θ]] Rotate counterclockwise by angle θ
Shearing [[1, k], [0, 1]] Shear in x-direction by factor k
Reflection [[1, 0], [0, -1]] Reflect across x-axis

Robot Rotation Example:

Camera rotates 45° counterclockwise. Object at (4, 3) transforms to:

Python Implementation: 
import numpy as np

theta = np.radians(45)  # 45 degrees
R = np.array([[np.cos(theta), -np.sin(theta)],
              [np.sin(theta), np.cos(theta)]])

P = np.array([4, 3])
P_rotated = R @ P

print(f"Original position: {P}")
print(f"Rotated position: [{P_rotated[0]:.4f}, {P_rotated[1]:.4f}]")
Output: Original position: [4 3] Rotated position: [0.7071, 4.9497]

Laboratory Implementations

Lab 1: Spring-Mass System Analysis

Problem: Two masses connected by springs. Calculate displacement under applied force.

Physical Model:

Force on mass m₁: F₁ = -k₁x₁ + k₂(x₂ - x₁) Force on mass m₂: F₂ = -k₂(x₂ - x₁) At equilibrium: Sum of forces = 0 Matrix form: Kx = F where K is stiffness matrix

System Parameters:

  • k₁ = 10 N/m (spring constant)
  • k₂ = 5 N/m
  • F = 20 N (applied force)
Python Solution: 
import numpy as np

# Spring constants
k1, k2 = 10, 5

# Stiffness matrix for 2-mass system
# K = [[k1+k2, -k2], [-k2, k2]]
K = np.array([[k1+k2, -k2], [-k2, k2]])

# Applied forces
F = np.array([20, 0])  # 20N on mass 1, 0 on mass 2

# Solve: K*x = F
displacements = np.linalg.solve(K, F)

print(f"Stiffness Matrix K:")
print(K)
print(f"\nApplied Forces: {F}")
print(f"\nDisplacements:")
print(f"x1 = {displacements[0]:.4f} m")
print(f"x2 = {displacements[1]:.4f} m")
Output: Stiffness Matrix K: [[15 -5] [-5 5]] Applied Forces: [20 0] Displacements: x1 = 2.0000 m
